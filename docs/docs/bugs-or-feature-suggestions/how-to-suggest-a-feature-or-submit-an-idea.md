# How to suggest a feature or submit an idea

There are several ways to suggest a feature or share an idea:

* **Feedback in GovTool**: click on the "Feedback" button in the footer of GovTool. A support chat window will open where you can describe your idea and add attachments.
* **GitHub Discussions**: start or join a thread in [GitHub Discussions → Ideas](https://github.com/IntersectMBO/govtool/discussions/categories/ideas). Someone may already have had the same or a similar idea.
* **GitHub issue**: submit a [Feature idea](https://github.com/IntersectMBO/govtool/issues/new/choose) using one of the feature templates (a GitHub account is required).

When describing your idea, include the problem you want to solve, who it would help, and how you imagine it working in GovTool.
