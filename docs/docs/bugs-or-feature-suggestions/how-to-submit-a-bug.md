# How to submit a bug

First check against list of [Known Issues](../overview/system-status.md), and search the [existing GitHub issues](https://github.com/IntersectMBO/govtool/issues) to see if the bug has already been reported.

There are two ways to report a bug:

## Option 1: Feedback in GovTool

1. Click on the "Feedback" button in the footer of GovTool.
2. A support chat window will open. Describe the bug or issue: what you were doing, what you expected to happen, and what happened instead.
3. Attach a screenshot or video if it helps to explain the issue.

## Option 2: GitHub

1. Open a [Bug report](https://github.com/IntersectMBO/govtool/issues/new?template=bug_report.yml) on GitHub (a GitHub account is required).
2. Select the GovTool instance you were using (for example gov.tools or preview.gov.tools) and fill in the form.
3. Click "Create" to submit the report.

:::warning
Bug reports on GitHub are public. Never include your seed phrase, private keys, or other sensitive information in a bug report or chat message.
:::
