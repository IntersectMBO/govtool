# View Governance Actions

## Starting from the Landing Page

Open "Governance Actions" in the top menu. The page has three tabs: "Proposed" (proposals under discussion, where the proposal discussion forum is enabled), "Live Voting" and "Outcomes" (results of past Governance Actions).

"Governance Activity", also in the top menu, shows what is happening across governance: how many actions are open and how many deadlines fall in the next 7 days, a timeline of actions opening for voting and being decided, the latest ratifications, and a searchable list of the actions open for voting, with their deadlines in UTC.

## The Governance Actions Page

The Live Voting tab lists the actions open for voting:

1. Search box, enter any Governance Action ID, title, keyword, etc.
2. Action type filter, in a sidebar beside the list (behind a "Filters" button on phones). You will be able to choose which types of Actions you want to see.
3. Sort order. You can sort Governance Actions by "Soon to expire", "Newest first", or "Highest amount of 'Yes' votes"
4. Each row shows the action's type, title, time left and the DRep, SPO and Constitutional Committee tallies.
5. "View details" Click on this to see detailed info.
6. Page numbers below the list.

## The Governance Action detail page

If you Click on "View Details", you will be taken to a detail screen for that particular proposal

1. Title
2. Governance Action type
3. Submitted and Expiry dates and epochs
4. Share button
5. Governance Action ID (CIP-129 format), and the Legacy Governance Action ID (CIP-105)
6. Governance Action details
7. Vote tally, including the ratification threshold for each voter group. See [How Governance Action Vote Totals are Calculated in GovTool](../../faqs/how-governance-action-vote-totals-are-calculated-in-govtool.md).
