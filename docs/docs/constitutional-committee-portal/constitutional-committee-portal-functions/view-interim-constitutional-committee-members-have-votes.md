# View how Constitutional Committee Members have voted

Navigating to the Voting Updates page using the navigation bar, will show you a list of votes made by the CC members who are registered on the Constitutional Committee Portal. Displaying:

* The name and picture of the CC member
* The vote transaction ID
* The title of the governance action (if available)
* The type of governance action
* How the member voted ("YES"/ "NO"/ "ABSTAIN")
* The rationale posted by the CC member (if available)

You can also select "Show more" to have a closer look at the rationale posted by the CC member (if available)
